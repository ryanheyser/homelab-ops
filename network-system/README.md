# network-system

This namespace contains the cluster networking and edge services that expose, secure, and route traffic around the homelab.

Current components include:

* [adguard](adguard/)
* [authentik](authentik/)
* [blocky](blocky/)
* [calico](calico/)
* [cloudflare-ddns](cloudflare-ddns/)
* [metallb](metallb/)
* [tailscale](tailscale/)
* [traefik](traefik/)

These workloads handle DNS, ingress, load balancing, identity, and external connectivity for the cluster.
