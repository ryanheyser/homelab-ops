# kube-system

This namespace contains cluster-level support services that improve scheduling, storage integrations, and operational reliability.

Current components include:

* [admission-policy](admission-policy/)
* [descheduler](descheduler/)
* [external-secrets](external-secrets/)
* [hami](hami/)
* [intel-device-plugins](intel-device-plugins/)
* [node-feature-discovery](node-feature-discovery/)
* [reflector](reflector/)
* [reloader](reloader/)

These workloads provide policy enforcement, node optimization, secret syncing, device discovery, and lifecycle automation for the broader cluster.
